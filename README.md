# Dr. Majid N. V. — Academic Website

A responsive, static academic website built with HTML, CSS and a small amount of JavaScript.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive blue-and-white design
- `script.js` — mobile navigation and automatic footer year

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. For a local development server, open a terminal in this folder and run `python -m http.server 8000`, then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, `script.js` and the `assets` folder (if you add files).
3. Open the repository's **Settings → Pages**.
4. Select deployment from the `main` branch and the root folder, then save.
5. Wait for the published URL shown in the Pages settings.

## Before publishing
- Replace or supplement the monogram in the hero with your own approved professional photograph if desired.
- Check every publication title, journal detail, conference entry and identifier against your current CV and Google Scholar.
- Add DOI and journal links only after verifying them.
- Confirm the email address and all profile URLs.
- Add a PDF CV download link if you wish; place the PDF in the site folder and link to it from the page.

## Google Sites note
This is a **standalone custom HTML website**. Google Sites can embed HTML/CSS/JavaScript through **Insert → Embed → Embed code**, but a full custom site may be easier to maintain and publish with static hosting such as GitHub Pages. Google Sites' embed runs inside a frame and may not behave exactly like a standalone site.
